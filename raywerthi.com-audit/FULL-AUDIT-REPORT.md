# Полный SEO-аудит — raywerthi.com

**Дата аудита:** 8 сентября 2026
**Тип бизнеса:** Локальный сервис / гибрид (офис в Ереване + обслуживание Армении и Грузии) — официальный представитель HELLA, WAREMA, Silent Gliss (солнцезащитные и фасадные системы)
**Проверено страниц:** 6 (весь sitemap.xml)

---

## Executive Summary

## SEO Health Score: 28 / 100

Это очень низкий результат, но у него **одна доминирующая причина**, а не десятки разрозненных проблем: сайт (React/Vite SPA на Vercel) развёрнут без fallback-роутинга для клиентских маршрутов. В результате **5 из 6 страниц сайта — `/solutions`, `/services`, `/portfolio`, `/about`, `/contacts` — отдают настоящую серверную ошибку 404** при прямом запросе (именно так Google, Bing, AI-краулеры и реальные пользователи по ссылке/закладке/обновлению страницы получают эти URL). Работает только главная страница `/`.

Это подтвердили **независимо 6 из 10 субагентов** (technical, sitemap, content, schema, local, geo, sxo, visual, performance) — каждый своим методом (`curl`, forced Playwright render, скриншоты, живой поиск в Google). Практическое следствие: **сайт не появляется в выдаче Google ни по одному из 5 проверенных релевантных запросов**, включая брендовые запросы вроде «HELLA официальный представитель Армения», где вместо RayWerThi ранжируется случайный магазин автозапчастей.

### Топ-5 критичных проблем

1. **Vercel SPA routing bug** — 5 из 6 страниц отдают 404 при прямом заходе. Корневая причина почти всех остальных находок.
2. **Нет SSR/pre-rendering** — даже главная страница отдаёт краулерам без JS пустой `<div id="root"></div>`. AI-краулеры (GPTBot, ClaudeBot, PerplexityBot) не видят вообще ничего.
3. **Сайт не найден в Google** ни по одному из 5 проверенных целевых запросов — конкуренты и даже нерелевантный бизнес обгоняют RayWerThi.
4. **Структурированные данные сломаны** — два конфликтующих JSON-LD блока с разными названиями компании («Raywerthi» vs «Raywerthi Solutions Hub»), в LocalBusiness отсутствует адрес и геокоординаты.
5. **Нет доказательств присутствия в Грузии**, хотя сайт заявляет об этом — один адрес, один армянский телефон, все проекты в портфолио — только по Еревану.

### Топ-5 быстрых побед (Quick Wins)

1. Добавить `vercel.json` с rewrite-правилом для SPA-fallback — 5 минут конфигурации, разблокирует 5 из 6 страниц. **Самый выгодный фикс во всём аудите.**
2. Объединить два конфликтующих JSON-LD блока Organization/LocalBusiness в один, с реальным названием «RayWerThi» и добавленным адресом (готовый сниппет в `findings/schema.md`).
3. Добавить security-заголовки (CSP, X-Frame-Options, X-Content-Type-Options) через `vercel.json` — сейчас есть только HSTS.
4. Починить кнопки WhatsApp/Telegram на `/contacts` (сейчас `href="#"`) и сделать номер телефона кликабельным (`tel:`).
5. Заполнить полностью пустую секцию «Преимущества RayWerThi» — заголовок есть, контента под ним — ноль.

## Важное методологическое примечание

Полноценных измерений Core Web Vitals (PSI/CrUX/Lighthouse) получить не удалось из-за отсутствия Google API credentials и ограничений инструментов в рамках сессии — раздел производительности **оценочный**, а не измеренный, и явно помечен как таковой в соответствующем отчёте. Бэклинк-профиль оценён только на уровне Tier 0 (Common Crawl, без Moz/Bing) — «недостаточно данных» не означает «плохой профиль», а означает отсутствие измерения. Оба этих ограничения указаны в плане действий (Фаза 4) как задачи для повторного прогона после подключения соответствующих источников данных.
